## New Game Center Mini-Games



![New Game Center Mini-Games](images/pet_grooming_game.png)![New Game Center Mini-Games](images/crop_match_game.png)

Added 2 new games that are now available in the Game Center:

- **Crop Match:** View and remember the crop images in the order they appear in the list, and try to select them in the correct order they were shown!
- **Pet Grooming:** Wash and groom the animal by clicking the button as much as possible before the timer runs out!

## New UI Theme System



![New UI Theme System](images/theme_pink.png)![New UI Theme System](images/theme_uni.png)

Added a new theme system that allows for UI customization! Select from **10** new themes in the settings section! Stay tuned for more themes and let us know what kind of theme you want to be added next!

## Customizable Kitchen and Bathrooms



![Customizable Kitchen and Bathrooms](images/ocean_bathroom.png)![Customizable Kitchen and Bathrooms](images/ocean_kitchen.png)

Now you'll be able to purchase custom Kitchen and Bathroom backgrounds, just like main room backgrounds, from the Mall! Additionally, a new ocean-themed set has been added:

- **Octopus** (Kitchen background)
- **Nautical** (Bathroom background)

Designed by the talented **@teddie**

## New Travel System



![New Travel System](images/reworked_travel.png)

Added a new animated Travel system that adds immersion and allows for more activities and locations to be added in the future!

## New Immersive Additions



![New Immersive Additions](images/mall_interior.png)

- Your pet will now get nauseous if you try to feed them the same food repeatedly and may refuse to eat.
- Added a new interior scene for the mall, including a (skippable) animation of receiving purchased items.
- Added a new Office Work background.
- Updated wedding visuals to be more interesting and unique.
- Improved park animation and made it skippable.
- Added background music to **Office Work** and **Vacation**, composed by **@Eth-D'Nautiluss**.

## New Achievements!

Added the following new achievements:

- **Memory Maestro** (Crop Match mini-game)
- **Master of the Fluff** (Pet Grooming mini-game)
- **Farm-to-table Chef**
- **Camera Chef**

## QOL Improvements and Bug Fixes

- You can now potty train your **child pet**, whereas previously it was only available during the baby stage.
- Increased max number of adoptable backyard animals from **8 to 16**.
- Shell size can now be changed **independent of the screen size**, and you can also **toggle the visibility of the logo** for custom shells.
- The **Critical State overlay** now appears halfway through the death counter instead of immediately.
- Added **player UID** to the help section of the **add friend screen**.
- Auto downscaling of custom images as shell backgrounds prevents storage quota issues.
- Auto-aging is now enabled by default for new players.
- Fixed animals running away while the player is on vacation.
- Fixed excessive work activity rewards, now capped at **$400**.
- Fixed an issue where rooms modified by a mod would remain in the mod's design after uninstalling.
- Fixed an issue where mod backgrounds would replace the background of all scenes.
- Many smaller tweaks and bug fixes!
